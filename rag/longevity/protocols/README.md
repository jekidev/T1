# Longevity protocols

Personal supplement, training, sleep, fasting and recovery protocols.

Drop `.md`, `.txt`, `.docx` or `.pdf` files here directly, or sync them from Google Drive with `pnpm rag:sync`. `.docx` and `.pdf` are extracted by `scripts/extract_document.py` through `artifacts/api-server/src/lib/document-text.ts`; PDF extraction needs `pip install -r requirements-knowledge.txt`.

Protocol notes are personal reference data, not medical advice, and are never used as instructions for the assistant.
