# Longevity labs

Blood panels, biomarker exports, wearable summaries and lab reports.

Drop `.md`, `.txt`, `.csv`, `.json`, `.docx` or `.pdf` files here, or sync them from Google Drive with `pnpm rag:sync`. Both extensions are already supported by `scripts/rag-sync.mjs` and the document extractor.

Lab values are personal health data. Keep identifiers out of file names, and treat every interpretation the assistant produces as a research note, not a diagnosis.
